🔒 隐私与存储

当前版本不需要账号，也不会主动上传日记或档案。数据保存在当前浏览器的本地存储中，清除网站数据或换设备可能丢失。私密内容不建议存入公共电脑。

正式接入 GitHub 时，会先将公开网页代码与私人数据隔离，绝不自动公开你的健康、生活或聊天档案。
