♡ 从日常有迹导入摄入

读取中…

检查导入状态…

在「日常有迹」的备份页面点击「导出 JSON」，再回这里选择下载的文件。会读取其中的真实饮食热量记录，按北京时间日期汇总。多条记录会合计并标注核对提醒。只在本机保存每日热量摘要，不上传私人健康数据。

目前不是实时同步：日常有迹采用仅本人可访问的 Google Apps Script，未提供安全的跨站数据接口。新记录需重新导入 JSON；这里不会显示虚假的实时状态。

✎ 本机手动摄入（可选）

手动记录会保存在本机。导入的日常有迹快照与手动记录会标明来源；手动记录不会写回私人 Google Sheet。未填写时显示「未记录」，不会冒充 0 kcal。

↗ 已有网站入口

绑定你已经在用的体重饮食和记账网站。网址只存当前浏览器，不公开到 GitHub。

没有填写日常有迹的网址时，会打开已确认的 Google Sheets 私人记录数据库。记账网址未知时不会编造链接。

📥 导入备份

从之前导出的 JSON 文件恢复。导入会替换本浏览器现有的记录，操作前会再次确认。

🔒 隐私与存储

当前版本不需要账号，也不会主动上传日记或档案。数据保存在当前浏览器的本地存储中，清除网站数据或换设备可能丢失。私密内容不建议存入公共电脑。

正式接入 GitHub 时，会先将公开网页代码与私人数据隔离，绝不自动公开你的健康、生活或聊天档案。
