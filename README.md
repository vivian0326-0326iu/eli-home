# eli 的小家 · 时光博物馆

温柔的 2D 虚拟小家，包含房间、换装、日记、时光博物馆和 JSON 备份。

## 当前版本 V0.10

- 首页与房间页面同步四种手动选择的氛围：晴日卧室、星灯夜晚、窗边工作角、雨声小屋。
- 房间加入光晕、星光、雨丝、场景介绍、缩略图和一键切换。夜晚和雨天是美术主题，并非真实天气。
- 两张原有房间插画已从 CSS 中抽出为独立 WebP 文件；清理旧版无用的图片代码，减轻加载体积。
- eli 的原始人物插画单独显示在角色区，房间主图不叠人物。
- **人物只使用原画图片**：恢复原有 10 张 WebP 插画作为角色主视觉，移除 SVG 卡通人物和“原画参考”小图。衣服、颜色、表情偏好分别保存；点击服装或表情时显示对应完整原画。由于现有原图无法拆分，当前不能把三项合成一张图，页面会明确说明颜色偏好不改变原画。
- **V0.7 插画替换**：使用用户认可的暖色动漫插画，6 张不同服装图片和 4 张表情图片，直接切换 `<img>`，不再把颜色叠在旧照片上。
- 房间背景保持原样，角色换成接近规划图画风的真实 WebP 插画。
- 服装和情绪都可在首页和衣柜切换，选择保存在本机。主图显示最近选择的服装图或表情图；没有用 SVG 或小图伪装成组合效果。
- 三种房间氛围：白天、夜晚、工作角。
- 日记与博物馆：新增、编辑、删除、分类、搜索；记忆条目保留来源和日期。
- 数据仅保存在当前浏览器 localStorage；可导入、导出 JSON 备份。设置页面会展示本机日记、藏品和摄入记录数。
- 生活中心支持**导入「日常有迹」网页导出的真实 JSON 备份**，按北京时间日期提取饮食热量，记录数值、来源、导入时间和是否确认全天。同日多条数值合计并提示核对。仅保留热量摘要，不把原始健康记录发布到仓库。
- **并非实时同步**：已连接的 Google Drive 读取授权只在当前连接器会话中可用，公开 GitHub Pages 不能继承该授权。健康表中的网页 Apps Script 部署状态标为“尚未部署”，现有源码要求仅本人访问。要让主页实时读取，仍需部署经过身份验证的私人接口；此前不会把健康数值写进公开仓库。当前保留真实 JSON 快照导入，并标注来源和非实时状态。
- 备份包含日记、藏品、房间、衣柜、独立颜色、心情、生活中心手动摄入、日常有迹热量摘要和两个网站入口；**不会**自动读取或同步外部私人数据库。
- 桌面和手机布局，支持离线缓存，支持系统减少动态效果偏好。
- 拆分 HTML、CSS、JS，方便后续维护。无需后端，也不依赖外部 CDN。

## 隐私说明

**此仓库公开，但不会自动上传用户日记或记忆。** 只有网页代码、公共美术和两条非敏感项目示例。请不要提交个人日记、聊天记录、健康资料、密码、令牌或导出的 JSON 文件。

数据不会跨设备自动同步；清除浏览器网站数据可能丢失，建议定期下载备份。导出的 JSON 是明文。

仓库管理员打开 **Settings → Pages → Build and deployment → Deploy from a branch**，选择 **main**、**/(root)**，然后保存。

部署成功后网站地址通常是：

## 本地运行

`python3 -m http.server 8000`，浏览器访问 `http://localhost:8000`。

## 版本升级

本次继续沿用 `eli-home-mvp-v1` 和 `eli-home-life-v1` 本地存储键，避免清空旧版本保存的记录。新增房间主题不改变原有数据结构。更新前仍建议导出备份。

**数据边界：** 发布静态代码无法直接修改用户 iPhone 浏览器中的 localStorage，也无法直接读取私人 Google Apps Script / 记账网站里的最新数据。主页今日摄入优先显示已导入的当天真实热量摘要或较新的手动记录，并明确标记数据来源与非实时状态；没有当天记录时显示「未记录」，不会填 0 或套用历史值。
